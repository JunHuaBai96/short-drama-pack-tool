# ShortDramaPackTool · 短剧推广素材整理工具

Windows 桌面小工具：**手动输入 / 左侧剧名列表按行批量加入 / 工作台导入**提取短剧信息，实时检索任务页匹配官方剧情简介，并按固定规则生成可直接复制投放的推广素材。

## 功能

1. **手动输入剧名**：左侧文本框每行一个，点「按行加入右侧」批量建页（自动跳过空行、保持顺序）
2. **工作台导入**：通过北斗 MCP 网关（用户 api-key）导入推广工作台待发布剧目
3. **官方简介实时匹配**：实时检索任务页（inbeidou.cn/task 数据源，全部排序组合覆盖，禁止缓存），按标题模糊匹配（支持截断剧名前缀匹配）
4. **忠实原文输出**：简介不编造不增删；匹配不到或疑似截断时，界面标注「页面未提供完整简介」并提示手动粘贴补全
5. **剧集管理**：删除当前剧集 / 删除全部剧集（均带确认）
6. **关键词库**：3–20 个 `#` 开头、适合 Facebook Reels 的推广关键词（LLM 或按题材智能匹配，可编辑）
7. **标题生成**：LLM 生成（配置 Key 后）或题材模板 + 通用模板英文标题草稿（可编辑），数量可调 5–20 条
8. **一键复制**：单部复制 / 全部复制，结果仅显示在工具界面，不落盘

## 安装

### 方式一：直接使用（推荐）

到 [Releases](../../releases) 下载 `ShortDramaPackTool.exe`，双击运行即可。

- 无需安装 Python
- Windows 10 / 11

### 方式二：从源码运行

```bat
git clone https://github.com/JunHuaBai96/short-drama-pack-tool.git
cd short-drama-pack-tool
python short_drama_pack_tool.py
```

仅需 Python 3.10+（纯标准库，零第三方依赖）。

### 从源码打包 exe

```bat
pip install pyinstaller
pyinstaller --onefile --windowed --name ShortDramaPackTool --icon app.ico short_drama_pack_tool.py
```

产物在 `dist/ShortDramaPackTool.exe`。

## 使用方法

1. 在左侧文本框粘贴剧名（每行一个），点 **「按行加入右侧」** 批量建页
   —— 或者点 **「1️⃣ 导入北斗推广工作台待发布剧目」**（首次会弹出设置，粘贴你的北斗 api-key）
2. 点 **「2️⃣ 匹配简介（实时检索任务页）」**：实时拉取任务页数据匹配官方简介；没匹配到的剧集按提示手动粘贴简介补全
3. 每部剧的标签页里：设置关键词数量（3–20）与标题数量（5–20），点 **「生成关键词与标题」**；多余剧用 **「🗑 删除当前剧集」** 移除，或 **「🗑🗑 删除全部剧集」** 一键清空
4. 检查 / 修改右侧内容后，点 **「复制本剧结果」** 或底部 **「📋 一键复制全部结果」**

## 输出格式

每部剧固定输出：

```
【剧名】保持页面原文，按页面顺序排列

【剧情简介】忠实原文，缺失时标注「页面未提供完整简介」

【关键词库】# 开头关键词（数量可调）

【N 条标题】语言与剧名一致，与简介相符
```

## 隐私与数据

- 任务池缓存保存在 `%LOCALAPPDATA%\ShortDramaPackTool\pool_cache.json`
- 除匹配简介的网络请求外，所有数据只在本机处理；结果只存在于界面与剪贴板，不写文件
